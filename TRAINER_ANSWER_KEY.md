# Trainer Answer Key

## Pass criteria for clean events

- Correct event appears in GTM Preview.
- Correct GA4 tag fires once.
- Required event parameters are populated.
- Trainee captures evidence and explains expected vs actual.

## Pass criteria for broken scenarios

- Scenario 1: trainee identifies `request_demo_clik` typo.
- Scenario 2: trainee identifies missing `resource_name` despite `file_download` firing.
- Scenario 3: trainee identifies duplicate firing from one click.
- Scenario 4: trainee identifies `generateLead` casing issue vs `generate_lead` standard.

## Scoring rubric

- 4: finds issue, explains impact, recommends correct fix, provides evidence.
- 3: finds issue and evidence, impact or fix is incomplete.
- 2: knows something is wrong but cannot isolate root cause.
- 1: only checks whether a tag fired and misses data quality issues.
